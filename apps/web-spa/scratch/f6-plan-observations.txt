3절. storybook init 이 에이전트를 감지한다 (--agent / --no-agent)
================================================================
`storybook init --help` 에 플래그가 있다:
  --agent      Force agent mode (non-interactive, logs AI setup instructions)
  --no-agent   Force disable agent mode even when an AI agent is detected

=> 도구가 실행 주체를 보고 동작을 바꾼다. F-1(커버리지 표 45↔103행)·F-2(watch 기본값)·
   F-3(console.log 소멸)·H-1~H-4 에 이은 계열. 이번엔 「출력」이 아니라 「설치 절차」다.
   그래서 모든 실행을 env -u AI_AGENT -u CLAUDECODE -u CLAUDE_CODE + --no-agent 로 했다.

6절. 배선을 손으로 마저 채웠다
================================================================
설치가 끝난 뒤 postinstall 을 다시 돌렸다:
  (main.ts 의 addon-vitest 줄을 임시로 지워 프롬프트를 없앤 뒤)
  npx storybook add @storybook/addon-vitest --skip-install
  => "Updating your Vitest config file" + "a11y addon setup successfully" + Done!

vitest.config.ts 가 projects 2개로 재구성됨:
  [0] 기존 jsdom 프로젝트 — environment/globals/setupFiles/exclude(e2e) '전부 보존'
      (우리가 쓴 한국어 주석도 그대로 살아남았다)
  [1] name:'storybook' — storybookTest({configDir}) + browser.provider playwright chromium headless

preview.tsx 에 a11y 설정이 붙었다:
  a11y: { test: 'todo' }
  주석 원문: 'todo' - show a11y violations in the test UI only
             'error' - fail CI on a11y violations
             'off' - skip a11y checks entirely
⚠️ 기본값 'todo' 는 '아무것도 실패시키지 않는다'. 커리큘럼의 「a11y 자동 검사」는
   'error' 로 바꿔야 성립한다. 「침묵은 통과가 아니다」 게이트 캐논의 재현.
