[3] ⚠️⚠️ 손으로 짠 핸드셰이크가 두 번 거절당했다 — 둘 다 클라이언트가 알려줬다
------------------------------------------------------------
(a) "Server did not respond with sent protocols."
    stompjs 는 Sec-WebSocket-Protocol: v12.stomp, v11.stomp, v10.stomp 를 내밀고
    서버가 그중 하나를 골라 돌려주기를 기다린다. 안 돌려주면 연결을 끊는다.
    → selectProtocol 로 v12.stomp 를 골라 응답 헤더에 실었다.

(b) "Incorrect hash received in Sec-WebSocket-Accept header."
    ★ 내가 쓴 고정 문자열(GUID)이 틀렸다. 눈으로는 안 잡혔다.
      틀린 것: 258EAFA5-E914-47DA-95CA-5AB0DC85B11F   ← C 가 앞으로 가고 F 가 붙음
      맞는 것: 258EAFA5-E914-47DA-95CA-C5AB0DC85B11
    확인 방법: RFC 예시 키 dGhlIHNhbXBsZSBub25jZQ== 를 넣으면
      s3pPLMBiTxaQ9kYGzzhZRbK+xOo= 가 나와야 한다(맞는 것으로 하면 나온다).
    ★ 한 글자 자리바꿈을 사람 눈으로 찾으려 하지 말 것 — 규격이 준 시험값으로 대조한다.


[4] SockJS 를 안 쓰는 이유 (교안에서 한 줄로 짚을 것)
------------------------------------------------------------
레거시 백엔드는 .withSockJS() 가 붙어 있다. 그러나
  - sockjs-client 는 2022-10 이후 새 릴리스가 없다
  - WebSocket 을 못 쓰는 브라우저가 이제 없다
  - spring-boot-advanced 커리큘럼 C-2 도 "SockJS 불필요 이유" 를 항목으로 둔다
→ 우리는 날 WebSocket 으로 붙는다. 다만 학생이 회사 코드에서 만날 수 있으니 이름은 짚는다.


[5] 실물 대조 — @stomp/stompjs 7.3.0 이 우리 브로커에 붙는다 (probe 4/4)
------------------------------------------------------------
스크립트: apps/web-spa/scratch/c8-stomp-probe.mjs
서버: DELAY_MS=0 node apps/api-stub/server.mjs

  1) CONNECTED   ok
  2) SUBSCRIBE   ok
  3) /app/ping → /topic/pong
       {"response":"PONG: 안녕하세요","timestamp":1787016806523}
  4) REST 좋아요 → 열려 있는 연결에 푸시
       {"type":"like","postId":1,"likeCount":1241,"actor":"jaehoon"}

★ 4) 가 이 모듈의 핵심 교보재다. 좋아요는 여전히 C-6 의 REST 뮤테이션으로 가는데,
   결과가 누른 사람에게만 돌아오지 않고 열려 있는 모든 연결로 나간다.
   두 탭을 띄우면 한쪽에서 누른 것이 다른 쪽에 뜬다 — 흉내가 아니라 진짜 두 클라이언트다.

실제 오간 프레임 (stompjs debug 원문 — 교안 Step 4 교보재):
  >>> CONNECT
  login:jaehoon
  accept-version:1.2,1.1,1.0
  heart-beat:10000,10000

  <<< CONNECTED
  user-name:jaehoon
  session:sess-1
  heart-beat:10000,10000
  version:1.2

  >>> SUBSCRIBE
  id:sub-0
  destination:/topic/posts

  >>> SEND
  destination:/app/ping

서버 로그:
  [stomp] jaehoon 님이 연결했습니다 (sess-1) — 전체 1
  [stomp] 구독 /topic/posts (sess-1)

⚠️ stompjs debug 에 "connected to server undefined" 가 찍힌다 —
   CONNECTED 프레임에 server 헤더가 없어서다. Spring 도 안 보낸다. 정상.
