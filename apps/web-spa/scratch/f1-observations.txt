isAgent 출처: std-env. AI_AGENT 를 가장 먼저 보고, 없으면 CLAUDECODE/CLAUDE_CODE,
  REPL_ID, GEMINI_CLI, CODEX_*, CURSOR_AGENT ... 를 차례로 본다.

이 세션 환경: AI_AGENT=claude-code_2-1-220_agent · CLAUDECODE 설정됨

같은 코드·같은 명령의 표 행 수 (scratch 제외 후, 전체 103 파일):
  이 세션 기본                   45 행   + text-summary 블록 있음
  CLAUDECODE 만 걷기             44 행
  AI_AGENT 까지 걷기 (=학생)    103 행   + text-summary 블록 없음

제외 전(148 파일) 기준으로도 동일: 에이전트 81 행 / 사람 148 행
  81 = "네 지표 중 하나라도 100% 미만" 인 파일 수와 정확히 일치 (148-81=67)

⚠️ --coverage.skipFull=false 로는 못 되돌린다. 그 CLI 플래그는 coverage.skipFull
   (최상위)로 가는데, 위 코드가 건드리는 것은 text **리포터의 옵션**이다.
   되돌리려면 reporter: [['text', { skipFull:false }]] 로 줘야 한다.

★★ 교훈: 내가 잰 표는 학생 화면이 아니다. 그대로 교안에 썼으면 전원이 다른
