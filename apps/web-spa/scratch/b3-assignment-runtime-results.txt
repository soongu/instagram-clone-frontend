─────────────── 2단계 — 지금 피드로는 안 무너진다 ───────────────

src/data/feed.ts 의 캡션 길이 (CAPTION_LIMIT = 10)

  '오늘 한강 노을이 미쳤다'  → 13자  (> 10)
  '제주도 3박 4일 기록'      → 12자  (> 10)

둘 다 넘으므로 두 카드 모두 isLong 이 계속 true 다. 훅 개수가 렌더마다
같으니 화면은 멀쩡하다. 접기/펼치기도 그대로 동작한다.

  카드 2장 · '더 보기' 버튼 2개 · console.error 0건
  첫 카드 펼침 → "jaehoon 오늘 한강 노을이 미쳤다접기"

─────────────── 3단계 — 카드마다 훅 개수가 달라도 ───────────────

캡션이 '노을'(2자)인 게시물을 하나 더해 3장으로 만든다.

  카드 3장 · '더 보기' 버튼 2개(긴 캡션 카드에만) · console.error 0건
  세 번째 카드 = "seungwoo 노을"

카드 1·2 는 훅 1개, 카드 3 은 훅 0개인데도 아무 일이 없다.
React 가 훅 순서를 기억하는 단위가 "컴포넌트 인스턴스" 이기 때문이다.
카드가 세 장이면 인스턴스도 셋이고 훅 목록도 셋이라, 서로 개수가 달라도
각자의 순서만 매 렌더 일정하면 된다.

─────────────── 4단계 — 같은 카드 안에서 조건이 바뀌면 ───────────────

같은 실험인데 "길이 바꾸기 버튼을 어디에 두느냐" 로 결과가 갈렸다.

(가) 버튼을 카드 쪽에 두고 content 를 props 로 내려보낸 경우
    → PostBody 가 가진 훅은 조건부 useToggle 하나뿐 → 훅 개수 0 ↔ 1

  짧게 → 길게 :  안 터짐 · console.error 0건 · '더 보기' 버튼이 나타남
  길게 → 짧게 :  안 터짐 · console.error 0건 · '더 보기' 버튼이 사라짐

  대신 상태가 조용히 초기화된다.
    1 처음      : "오늘 한강 노을이...더 보기"
    2 펼친 뒤   : "오늘 한강 노을이 미쳤다접기"
    3 짧게      : "노을"
    4 다시 길게 : "오늘 한강 노을이...더 보기"   ← 펼쳐둔 상태가 사라졌다

  이유: React 는 직전 렌더가 남긴 훅 상태가 하나도 없으면 그 렌더를
  "처음 그리는 것" 으로 취급한다. 0 → 1 은 새로 마운트하는 길이라
  에러가 아니라 새 상태를 만들어 버린다. 1 → 0 도 비교할 훅이 없어 조용하다.

(나) 버튼을 PostBody 안에 두어 캡션을 자기 상태로 들고 있는 경우
    → useState(캡션) 이 조건부 useToggle 앞에 생김 → 훅 개수 1 ↔ 2

  짧게 → 길게 (훅이 늘어남):

    화면: 통째로 사라진다 (document.body.textContent === '')

⚠️ 갈림의 기준은 "조건부 훅 말고 살아남는 훅이 하나라도 있느냐" 다.
   교안 Step 5 가 예로 든 ConditionalToggle 도 훅이 조건부 useState
   하나뿐이라 조건을 뒤집어도 두 방향 다 안 터진다(실측 확인).

─────────────── 5단계 — 슬롯에 함수를 넘기면 ───────────────

  <Card header={() => <p>jaehoon</p>}>노을 사진</Card>

브라우저를 열기 전에 걸린다. tsc 가 먼저 잡는다.

  scratch/b3-expected-errors.tsx(41,23): error TS2322:
    Type '() => React.JSX.Element' is not assignable to type 'ReactNode'.

에디터에 바로 빨간 줄이 뜨고, npm run typecheck 도 npm run build 도
여기서 멈춘다(build 스크립트가 tsc --noEmit && vite build 라서).

타입 검사를 억지로 통과시켜 실행까지 가면 — 페이지는 뜬다.

  아무것도 안 터짐 (throw 없음)
  <article class="post-card">노을 사진</article>   ← 머리말 자리만 비어 있음
  console.error 1건:
    Functions are not valid as a React child. This may happen if you return %s
    instead of <%s /> from render. Or maybe you meant to call this function
    rather than return it.
      <%s>{%s}</%s>
    (%s 에 채워지는 값: headerAsFunction / headerAsFunction / article /
     headerAsFunction / article)

앞의 훅 실험들과 정반대다. 훅 실험은 타입 검사를 멀쩡히 통과하고(타입상
아무 문제가 없다) 린트만 잡아주며, 그마저 무시하면 실행 중 특정 조건에서만
터진다. 슬롯에 함수를 넣는 실수는 타입 검사가 먼저 잡고, 뚫고 나가도
화면 한 자리가 조용히 비는 것으로 끝난다.
