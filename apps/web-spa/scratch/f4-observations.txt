        "서버가 켜져 있으면 통과" 가 안 나온다.
  원인을 재서 확정 — 같은 조건(서버 켬 · 핸들러 0개 · 'warn')에서:
        fetch              → 200 · 14ms      (진짜 서버까지 닿는다)
        XMLHttpRequest     → onerror
        axios (우리 인스턴스) → 던짐 '서버에 연결할 수 없어요'
    axios 는 이 환경에서 XHR 을 쓰고, jsdom 의 XHR 이 다른 주소로 나가는 것을 막는다.
    서버를 끄면 fetch 만 결과가 바뀌고(TypeError) axios 는 그대로다.
  => 지문을 "fetch 와 api 인스턴스를 같은 조건에서 비교하라" 로 다시 썼고,
     교안 Step 3 에도 ⚠️ 절을 신설했다. 표가 fetch 로 잰 값이라는 측정 조건도 명시.
  ★ 이 실측이 없었으면 교안이 "목록에 없으면 진짜 서버 답을 받는다" 를
    우리 앱에도 참인 것처럼 서술할 뻔했다.
